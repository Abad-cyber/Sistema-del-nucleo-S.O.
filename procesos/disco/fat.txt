# Asignación FAT (File Allocation Table)
# =========================================
# Método: FAT
# Formato: archivo, bloque1, bloque2, bloque3, ...
#
# Igual que enlazada, pero los punteros NO se guardan en los bloques.
# En cambio, se almacenan en una tabla FAT centralizada.
# Ventaja: los bloques de datos aprovechan el 100% del espacio del bloque.
#
# La tabla FAT se muestra en la sección de Metadatos del simulador.
# Ejemplo de tabla FAT generada:
#   FAT[5]→12, FAT[12]→30, FAT[30]→EOF
#
# Disco recomendado: 120 bloques, bloque 512 bytes
# =========================================
AA, 5, 12, 30, 44, 78
BB, 8, 17, 25, 38, 62, 91
CC, 1, 15, 23, 55
DD, 7, 19, 33
EE, 50, 60, 70, 80, 95, 105, 115
