# Asignación ENLAZADA (Linked Allocation)
# ==========================================
# Método: Enlazada
# Formato: archivo, bloque1, bloque2, bloque3, ...
#
# Cada bloque contiene un puntero al siguiente.
# El último bloque tiene puntero EOF (-1).
# Los bloques NO necesitan ser contiguos.
#
# Disco recomendado: 120 bloques, bloque 512 bytes, puntero 4 bytes
# ==========================================
AA, 5, 12, 30, 44, 78
BB, 8, 17, 25, 38, 62, 91
CC, 1, 15, 23, 55
DD, 7, 19, 33
EE, 50, 60, 70, 80, 95, 105, 115
