# Asignación INDEXADA MULTI-NIVEL (2 niveles)
# ==============================================
# Método: Indexada Multi-Nivel
# Formato de la tabla (4 columnas separadas por comas):
#   columna 1: nombre del archivo
#   columna 2: bloque índice RAÍZ (nivel 1)
#   columna 3: índices nivel 2 (separados por espacio)
#   columna 4: bloques de datos (separados por espacio)
#
# Estructura:
#   Bloque raíz → apunta a bloques índice nivel 2
#   Bloques nivel 2 → apuntan a bloques de datos
#
# Útil para archivos MUY grandes donde un solo bloque índice
# no puede almacenar todos los punteros.
#
# Disco recomendado: 120 bloques, bloque 512 bytes, puntero 4 bytes
# ==============================================

BB, 11, 21 31 41, 9 13 14 16 17 18 22 23 24 26 27 28
